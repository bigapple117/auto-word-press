   구글 라이브러리 기본값이 '무제한 대기'라서, 음성 서버가 응답 없이 멈추면 실행기 전체(다음 글 작성까지)가 멈출 수 있었습니다. 글 쓰는 쪽(ai_generator)에는 이미 제한이 있었고 음성 쪽에만 빠져 있었습니다. 180초로 제한하고, 넘으면 기존 음성(선희)으로 대체합니다.
2. **Gemini 음성이 '예상한 종류'의 오류일 때만 기존 음성으로 대체** — `src/pipeline.py`
   ffmpeg 시간 초과, 이상한 음성 파일 같은 다른 오류는 대체하지 않고 작업 자체가 실패했습니다. 어떤 오류든 기존 음성으로 대체하게 했습니다.
3. **숫자 읽기 오류** — `src/gemini_tts.py spoken_text`
   - `2025-2026년` → "이공이오 이공이육년"(전화번호처럼 읽음) → 이제 "이천이십오에서 이천이십육년"
   - `1,2월` → "십이월"(12월로 바뀜) → 이제 "일, 이월"
   - `10만~20만 원` → 물결표가 그대로 남음 → 이제 "십만에서 이십만 원"
   - `2026-11-10`, `2026.12.31.` 같은 날짜 → "2026년 11월 10일"로 읽음
   - 전화번호는 실제 형식(02-123-4567, 010-…, 1588-1234)만 숫자 하나씩 읽음
4. **계속 실패하던 테스트 1개** — `tests/test_orchestrator.py`
   [다음 승인 대기 글 보기] 버튼이 '다시 보내기' 대신 '원래 메시지에 답장'으로 바뀌었는데(7e59ee7) 테스트는 예전 동작을 기대하고 있었습니다. 원래 메시지가 지워졌을 때 다시 보내는 경우를 시험하도록 맞췄습니다. 코드 쪽 문제는 아니었습니다.
